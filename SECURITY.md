# Seguridad y privacidad

## Evidencia real

No publique archivos `History`, `History-wal`, `History-shm`, `analisis.json` ni informes generados con datos reales.

El repositorio excluye por defecto el contenido de `evidencia/` y `resultados/`.

## Uso

La herramienta está destinada a sistemas propios, laboratorios y entornos expresamente autorizados.

## Comportamiento

- analiza una copia del archivo `History`;
- no descifra contraseñas;
- no desactiva Defender ni SmartScreen;
- no cierra Chrome automáticamente;
- procesa el historial localmente.
